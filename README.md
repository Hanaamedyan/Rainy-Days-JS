# Rainy-Days

An interactive online store for a rain jacket brand called Rainy Days, which was built foer the JavaScript 1 assignment. The site fetches data from the Rainy Days API and lets the user browse, filter, and purchase (simulated) rain jackets through a shopping basket. The visual design is based on an earlier Figma design and HTML/CSS completed in earlier course.

## Features:

- Dynamic product listing on homepage, fetched from Rainy Days API
- Single product detail page with description, price, sale price, sizing and images
- Add to cart from product list and product pages
- Remove items and adjust quantities
- Cart state persists across all pages using `localStorage`
- Checkout page
- Simulated order confirmation
- Product filtering
- Terms & Conditions and Privacy Policy pages
- Acessible markup: skip link, visible focus states, `aria-live`, semantic headings
